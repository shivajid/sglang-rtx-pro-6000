# Executive Benchmark Report: `google/gemma-4-26B-A4B` on GKE Single GPU

Performance evaluation of **`google/gemma-4-26B-A4B`** served via **vLLM** on a single **NVIDIA RTX PRO 6000 Blackwell GPU** (`g4-standard-384`, TP=1, FP8 quantization).  
Benchmarked using **`sglang.bench_serving`** across concurrency levels **32 to 1024** over **4 workload patterns**.

## 🎯 6. Key Takeaways
1. **Peak Generation Bandwidth**: Reaches **4,054.82 output tok/s** on 1K/1K and **3,865.45 output tok/s** on 1K/512 from a single Blackwell GPU.
2. **Sub-250ms TTFT up to Concurrency 256**: For 1K input tokens, Median TTFT remains under **230 ms** across all workloads up to C=256.
3. **Smooth Streaming**: Median Inter-Token Latency (ITL) remains stable between **28 ms and 64 ms** across all workloads and concurrencies.
